# Plan: Plant Dropdown Navigation Enhancement

## Goal
Memperbaiki navigasi dropdown tanaman di Timeline agar mudah digunakan dengan 1000+ jenis tanaman.

## Current State
- `Timeline.tsx` menggunakan native `<select>` dengan semua tanaman dalam satu daftar
- `plantOptions` berisi array objek `{id, name}` dengan format `categoryId - variety`
- Ter-sortir alphabetically saja, tanpa pencarian atau группировка

## Proposed Solution (All-in-One UX)

### 1. Search/Autocomplete Component
- Text input untuk filtering real-time
- Fuzzy search pada nama tanaman
- Keyboard navigation (arrow keys, enter to select)

### 2. Grouped by Category
- Tanaman di-group berdasarkan `categoryId`
- Collapsible sections yang bisa di-expand/collapse
- Setiap group menunjukkan jumlah tanaman

### 3. Favorites/Pinned Plants
- Options untuk "pin" tanaman favorit di atas
- Disimpan di localStorage
- Hanya 5-10 tanaman favorit

### 4. Additional Improvements
- Pagination atau virtual scrolling untuk 1000+ items
- Keyboard shortcuts untuk navigasi cepat

## Files to Modify
- `src/components/Timeline.tsx` - Ganti `<select>` plant dengan custom dropdown

## Implementation Steps

### Step 1: Create PlantSelect Component
Buat component `PlantSelect` dengan:
- Search input dengan debounce
- Grouped list dengan collapsible sections
- Favorites section di top
- Virtual scrolling untuk performance

### Step 2: Integrate ke Timeline
- Ganti plant dropdown (lines 355-358) dengan `<PlantSelect>`
- Pass `plantOptions` dan `filterValue`

### Step 3: Add localStorage untuk Favorites
- Simpan array plant ID yang di-pin
- Load/save favorites

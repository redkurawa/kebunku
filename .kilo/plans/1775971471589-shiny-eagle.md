# Rencana: Filter & Sort pada Riwayat Aktivitas

## Tujuan
Menambahkan fitur filter dan sort pada halaman riwayat (Timeline) agar pengguna dapat:
1. Filter berdasarkan tanaman spesifik
2. Filter berdasarkan kategori
3. Filter berdasarkan kelompok
4. Mengatur urut tanggal ascending/descending

## Perubahan Needed

### 1. UI Filter Bar (Timeline.tsx)
Tambahkan filter controls di atas riwayat:
- **Select dropdown untuk Tanaman** - ambil dari `plants` hook
- **Select dropdown untuk Kategori** - unik dari plants.categoryId
- **Select dropdown untuk Kelompok** - unik dari plants.groupId  
- **Select dropdown untuk Urutan** - "Terbaru dulu" / "Terlama dulu"
- Tombol "Reset Filter" untuk clear semua filter

### 2. Logic Filtering (Timeline.tsx)
- State untuk menyimpan filter: `plantFilter`, `categoryFilter`, `groupFilter`, `sortOrder`
- Filtering kombinasi: jika user pilih tanaman MAKA category/group tetap bisa diklik untuk bantu ( atau auto-fill)
- Default sort: descending (terbaru dulu)

Update filtering logic:
```typescript
const filteredActivities = useMemo(() => {
  let result = [...activities];
  
  // Filter by type (existing)
  if (activeFilter !== 'all') {
    result = result.filter((a) => a.type === activeFilter);
  }
  
  // Filter by plant (activity.plantId)
  if (plantFilter !== 'all') {
    result = result.filter((a) => a.plantId === plantFilter);
  }
  
  // Filter by category
  if (categoryFilter !== 'all') {
    result = result.filter((a) => {
      const plant = plants.find(p => p.id === a.plantId);
      return plant?.categoryId === categoryFilter;
    });
  }
  
  // Filter by group
  if (groupFilter !== 'all') {
    result = result.filter((a) => {
      const plant = plants.find(p => p.id === a.plantId);
      return plant?.groupId === groupFilter;
    });
  }
  
  // Sort by date
  result.sort((a, b) => {
    const getMillis = (dateObj: any) => {
      if (dateObj && typeof dateObj.toMillis === 'function')
        return dateObj.toMillis();
      if (dateObj instanceof Date) return dateObj.getTime();
      if (typeof dateObj === 'string')
        return new Date(dateObj).getTime();
      return 0;
    };
    const diff = getMillis(b.date) - getMillis(a.date);
    return sortOrder === 'desc' ? diff : -diff;
  });
  
  return result;
}, [activities, activeFilter, plantFilter, categoryFilter, groupFilter, sortOrder, plants]);
```

### 4. UI Styling
Filter bar menggunakan style yang konsisten dengan existing activity type filter:
- 2 row layout: baris pertama filter aktivitas, baris kedua filter plant/category/group + sort
- Select dropdown dengan styling yang sama seperti button filter yang ada

### 5. Default Behavior
- Saat halaman dimuat: sortOrder = 'desc' (terbaru dulu)
- Semua filter = 'all'
- Sort order persist selama session (tidak perlu simpan ke localStorage，除非 diminta)
